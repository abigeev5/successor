Проанализируй последний ответ сотрудника в интервью о передаче дел преемнику.

Известные процессы (регулярные задачи сотрудника):
{% for p in processes %}- {{ p }}
{% else %}- (пока нет)
{% endfor %}
Сейчас обсуждается: {{ current_process or "общая картина работы" }}

Аспекты процесса:
{% for a in aspects %}- {{ a.key }} — {{ a.label }}
{% endfor %}
Вопрос интервьюера: {{ question }}
Ответ сотрудника: {{ answer }}

Верни JSON:
- aspects_touched — какие аспекты каких процессов раскрыты в ответе: process_name (название из списка или null, если речь о текущем процессе), aspect (ключ из списка), status:
  - "covered" — в ответе есть конкретная, применимая информация (шаги, признаки, роли, сроки, реальный случай);
  - "partial" — тема затронута, но без конкретики;
  - "not_applicable" — сотрудник прямо говорит, что так не бывает или это не относится к задаче;
- is_vague — true, если ответ общий, без конкретики («по ситуации», «как обычно», «по-разному»);
- vague_reason — коротко, чего не хватает, или null;
- new_processes — упомянутые регулярные задачи, которых нет в списке процессов: name (коротко, существительным: «Оформление пересдач»), description;
- key_facts — до 5 коротких фактов из ответа, своими словами.

Отмечай "covered" только если преемник сможет по этой информации действовать. Не выдумывай того, чего нет в ответе.
